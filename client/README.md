# RideIT Client (React + Vite)

This is the frontend for **RideIT**.

For full project setup (API + DB + endpoints), see the root README: `../README.md`.

## Requirements

- Node.js 18+

## Commands

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## API

The client calls the backend at:

`http://localhost:5000/api`

You can change the base URL in `src/services/api.js`.
